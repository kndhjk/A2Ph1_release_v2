# Ming Zhao Venture Lab

A bilingual, responsive static venture showcase for two early-stage commercial programmes:

1. Additive manufacturing / 3D printing in New Zealand and Pakistan
2. Tibetan culture-led wellness in China and New Zealand

## Features

- Pure HTML, CSS and JavaScript
- Chinese / English language switch
- Responsive layout
- Interactive venture tabs
- Scroll reveal animations
- Market and validation budget sections
- GitHub Pages ready
- Remote Unsplash images with credits in the footer

## Run locally

Open `index.html` directly, or run a local static server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to GitHub Pages

In the repository, open **Settings → Pages** and publish from the repository's default branch and `/ (root)`.

## Notes

The page is for early commercial validation and partnership conversations. It deliberately avoids claiming official Bambu Lab authorisation or medical treatment outcomes.
